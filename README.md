# Abra Freight Atlas — India

Interactive domestic freight advertising planner built with HTML, CSS, JavaScript and Leaflet.

## Features

- 104 curated industrial and distribution locations (47 original + 57 added to fill coverage gaps)
- Higher, High, Medium and Low planning priorities
- OpenStreetMap-based interactive map
- Search and state / freight filters
- Meta Ads targeting: suggested pin + radius (km) for every area, adjustable 1–80 km, map radius circles, copy-to-clipboard
- Browser-local shortlist and CSV export (includes lat, lng, radius_km)
- Responsive layout and methodology explanations

## Run

Serve this folder with any static web server, for example `python -m http.server 8000`, then open http://localhost:8000. No build step or API key is required. External map tiles, fonts and Leaflet require internet access.

## Scope

Priority ratings are editorial planning estimates, not official rankings or live shipment data. See the website's sources and methodology section. Verify operations coverage and lane economics before advertising.

Map data © OpenStreetMap contributors; HOT basemap. Leaflet is used for map interactions.
